# Sokoban 推箱子小游戏 README

## 项目简介

基于 C++ 控制台开发的经典推箱子游戏，仅依赖 Windows 系统 API 与标准 C++ 库，无需图形引擎，原生控制台运行；内置3个递进难度关卡，支持 WASD 移动、关卡重置、通关自动切关、全局通关判定，采用光标定位刷新画面，解决全屏清屏闪烁问题。

## 符号规则

| 字符 | 含义 |
| --- | --- |
| `#` | 墙壁，不可通行 |
| `@` | 玩家（站在空地） |
| `+` | 玩家站在终点格子 |
| `$` | 箱子（空地之上） |
| `*` | 箱子推至终点（完成目标） |
| `.` | 终点目标格子 |
| 空格 | 空白可走空地 |

## 操作说明

- `W` / `w`：向上移动
- `S` / `s`：向下移动
- `A` / `a`：向左移动
- `D` / `d`：向右移动
- `R` / `r`：重置当前关卡
- `Q` / `q`：退出游戏

## 游戏规则

1. 将所有箱子全部推到终点 `.` 上（全部变为 `*`）即通关本关；
2. 箱子无法穿过墙壁、其他箱子，仅前方为空地/终点时才可推动；
3. 单关通关后自动加载下一关卡，全部3关完成则游戏胜利结束；
4. 操作失误可按 R 一键重置当前关卡初始布局。

## 编译与运行环境

### 依赖头文件说明

- 标准库：`<iostream>` 输入输出、`<thread>` `<chrono>` 按键休眠防高占用
- Windows 专属：`<windows.h>` 控制台光标控制、`<conio.h>` `_kbhit/_getch` 无阻塞按键检测
- 通用工具：`<cstdlib>`

### 编译运行要求

1. 仅支持 **Windows 系统**（使用 Windows Console API，Linux/macOS 无法直接运行）
2. 编译工具：MinGW、Dev-C++、Visual Studio 均可
3. 编译命令（MinGW）

```
g++ sokoban.cpp -o sokoban.exe -luser32
```

4. 运行：双击生成的 `sokoban.exe` 控制台程序

## 核心功能亮点

1. **无闪烁画面刷新**：使用 `gotoxy` 光标定位至窗口左上角重绘地图，摒弃频繁清屏，消除画面闪烁；
2. **无阻塞按键检测**：`_kbhit` 轮询按键，搭配线程休眠降低 CPU 占用；
3. 多关卡系统：关卡数据二维数组统一存储，新增关卡仅需扩展 `levels` 数组与 `MAX_LEVEL`；
4. 完整边界校验：墙壁阻挡、箱子推动逻辑、玩家/箱子与终点叠加状态完整处理；
5. 通关自动跳转：单关完成自动加载下一关，全部关卡通关给出胜利提示；
6. 隐藏控制台光标，界面干净整洁。

## 拓展修改指南
